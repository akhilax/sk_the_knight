# SK the Knight

A 2D game made with Unity.

**Unity version:** 6000.5.9f1 (Unity 6)

## Opening the project

1. Install [Git LFS](https://git-lfs.com) (`git lfs install`) before cloning, since images and fonts are stored with LFS.
2. Clone the repo:
   ```
   git clone https://github.com/akhilax/sk_the_knight.git
   ```
3. In Unity Hub, click **Add → Add project from disk** and select the cloned folder.
4. Open it with Unity **6000.5.9f1**. The first open takes a while as Unity regenerates the `Library` folder.

## Play the game

A playable Windows build is available under [Releases](../../releases): download `knight_game.zip`, extract it, and run `sk_the_knight.exe`.
